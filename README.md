# grafana-monitoring-system


Hệ thống giám sát tập trung cho hạ tầng CNTT sử dụng Grafana Stack.

## 📋 Mục tiêu dự án
- Giám sát tài nguyên máy chủ (CPU, RAM, Disk, Network)
- Giám sát Web Server (Nginx/Apache)
- Giám sát Database (MySQL/PostgreSQL)
- Hệ thống cảnh báo đa kênh (Email, Slack)
- Dashboard tương tác với biến động
